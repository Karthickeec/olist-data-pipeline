# Small files: daily vs monthly partitions (Athena)

Generated by `scripts/small_files_experiment.py` on 2026-10-08 22:10 UTC (ap-southeast-2, workgroup `olist`).

The pipeline already writes **one file per partition**, so `coalesce` or `maxRecordsPerFile` can't
reduce the file count: the files are small because the partitions are **daily** (a few hundred
order lines per day). The only lever is coarser partitions. This experiment writes a monthly copy of
`gold_fact_order_lines` and runs the same queries on both; both return identical answers.
